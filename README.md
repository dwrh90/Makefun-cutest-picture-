# Cutest Picture — make.fun entry

Entry for the make.fun contest **"Make the cutest picture"**
(`cutest-picture-01`, $250 bounty, closes 13 Nov 2026 17:00 WIB).

The image is a fluffy orange kitten and a small puppy cuddling together
on a cozy knitted blanket, in soft warm light.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies the
bundled image `entry.png` byte-for-byte to `/output/entry.png`. The run is
fully deterministic: two runs produce identical output bytes.
